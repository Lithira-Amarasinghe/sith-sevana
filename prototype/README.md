# Sith Sevana design prototype

A clickable mobile prototype for the requirements conversation with Sith Sevana. It uses sample people, sample bookings, and a mock store. It does not call a real API.

```bash
cd prototype
npm install
npm run dev
```

Open http://localhost:5173

The phone is the product. The list on the left jumps to a screen. The panel on the right is what to confirm with Sith Sevana on that screen.

Sample sign-in, any password of 4 or more characters:

- `sanduni@sithsevana.test` — client
- `nadeesha@sithsevana.test` — counsellor
- `thilini@sithsevana.test` — applicant
- `malini@sithsevana.test` — staff

Reset restores the sample data.
